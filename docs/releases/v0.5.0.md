 """# Bharat Portfolio Lab v0.5.0

## Portfolio Optimisation, Stress Testing and User Portfolio Lab

Version 0.5 expands Bharat Portfolio Lab from a predefined strategy-research
application into an interactive Indian equity portfolio-analysis platform.

This document describes the v0.5 release candidate. Deployment occurs only
after the feature branch is reviewed and merged into `main`.

## Major additions

### Interactive User Portfolio Lab

Users can construct their own Indian listed-equity portfolio using:

- Portfolio weights
- Invested amounts in ₹
- Share quantities
- NSE or BSE trading symbols
- Nifty 50, BSE Sensex or a custom Yahoo Finance benchmark
- A user-selected historical analysis period

The application retrieves market data on demand and performs the complete
analysis using the submitted holdings.

### Portfolio optimisation

The production optimisation engine includes:

- Current portfolio analysis
- Equal-weight portfolio
- Minimum-volatility portfolio
- Maximum-Sharpe portfolio
- Risk-parity portfolio
- Ledoit-Wolf covariance estimation
- Expected-return shrinkage
- Minimum and maximum holding constraints
- Efficient-frontier construction
- Model-based and historically realised comparisons

### Risk and stress testing

The risk engine includes:

- Historical stress-period identification
- Portfolio stress comparison
- One-day historical VaR
- Expected Shortfall
- Block-bootstrap Monte Carlo simulation
- Probability of loss
- Terminal-return percentiles
- Bull, base and bear scenario analysis
- Concentration and diversification statistics

### User downloads

The User Portfolio Lab provides a downloadable ZIP package containing the
portfolio inputs, market-data quality checks, optimisation results, efficient
frontier, stress tests, Monte Carlo summaries and scenario results.

## India 10 research case

The original India 10 Adaptive Barbell Portfolio remains the default research
case for demonstrating the platform's portfolio methodology.

The India 10 results are precomputed research outputs. They are separate from
the interactive User Portfolio Lab, which supports arbitrary eligible Indian
listed equities.

## BSE data handling

For BSE securities:

- Users must enter the BSE trading symbol rather than a numeric scrip code.
- Quantity valuation uses the available BSE market price.
- When the data provider supplies insufficient BSE historical observations,
  the corresponding NSE trading-symbol history may be used for return
  analytics.
- Every BSE-to-NSE historical substitution is disclosed in the application and
  recorded in the data-quality output.

This fallback preserves analytical continuity but should not be interpreted as
the BSE and NSE price series being perfectly identical.

## Data and modelling limitations

- Market data is retrieved on demand and is not exchange real-time data.
- Historical results do not guarantee future performance.
- Optimised portfolios are sensitive to expected-return and covariance
  estimates.
- Monte Carlo results are model-based distributions rather than forecasts.
- VaR and Expected Shortfall do not capture every possible market outcome.
- Transaction costs, taxes, liquidity and execution may differ from model
  assumptions.
- The platform is intended for research and education, not personalised
  investment advice.
